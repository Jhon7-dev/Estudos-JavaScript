# Cadastro de Máquinas Agrícolas - JavaScript

Projeto desenvolvido para praticar manipulação de DOM, eventos e estrutura de dados utilizando JavaScript puro.

## 📚 Conceitos praticados

* Manipulação de DOM
* Eventos com `addEventListener`
* Captura de dados de formulário
* Arrays e Objetos
* `querySelector`
* `preventDefault`
* `innerHTML`
* Funções
* Estrutura de formulários

---

## 🚜 Funcionalidades

O sistema permite cadastrar máquinas agrícolas contendo:

* Nome da máquina
* Fabricante
* Potência

Após o envio do formulário, os dados são exibidos dinamicamente na tela.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* Tailwind CSS
* JavaScript

---

## 💡 Aprendizados

Durante o desenvolvimento deste projeto pratiquei:

* Como capturar dados digitados pelo usuário
* Como manipular elementos HTML com JavaScript
* Como trabalhar com arrays e objetos
* Como atualizar a interface dinamicamente
* Como utilizar eventos em formulários
* Organização básica de código JavaScript
