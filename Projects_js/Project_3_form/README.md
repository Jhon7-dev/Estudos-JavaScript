# Cadastro de Pessoas - JavaScript

Projeto desenvolvido para praticar conceitos fundamentais de JavaScript, manipulação de DOM e eventos em formulários.

## 📚 Conceitos praticados

* Manipulação de DOM
* Eventos com `addEventListener`
* Captura de dados de formulário
* Arrays e Objetos
* `querySelector`
* `preventDefault`
* `innerHTML`
* Funções
* Estrutura de formulários

---

## 🚀 Funcionalidades

* Cadastro de pessoas
* Captura:

  * Nome
  * Sobrenome
  * Peso
  * Altura
* Exibição dinâmica dos dados na tela
* Armazenamento temporário em array

---

## 🛠️ Tecnologias utilizadas

* HTML5
* Tailwind CSS
* JavaScript

---

## 💡 Aprendizados

Durante o desenvolvimento deste projeto pratiquei:

* Como selecionar elementos HTML utilizando `querySelector`
* Como capturar eventos de formulário
* Como impedir o recarregamento da página com `preventDefault`
* Como armazenar dados em arrays utilizando objetos
* Como atualizar o HTML dinamicamente com JavaScript

---

## 📷 Interface

Projeto com interface simples utilizando Tailwind CSS para estilização.
