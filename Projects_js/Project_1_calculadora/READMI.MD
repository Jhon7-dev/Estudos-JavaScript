# Calculadora Web em JavaScript

Projeto de uma calculadora funcional desenvolvida com HTML, CSS e JavaScript puro.

##  Funcionalidades

- Operações matemáticas básicas
- Adição
- Subtração
- Multiplicação
- Divisão
- Botão de limpar display
- Botão de apagar último caractere
- Resultado em tempo real

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

##  Conceitos praticados

- Manipulação do DOM
- Eventos com `onclick`
- Funções em JavaScript
- Métodos de string
- Estruturas condicionais
- Tratamento de erros com `try/catch`
- Organização de layout com CSS Grid

## Objetivo do projeto

Praticar fundamentos do desenvolvimento front-end e lógica de programação através da construção de uma aplicação funcional utilizando JavaScript puro.
