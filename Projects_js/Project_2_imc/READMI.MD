# Calculadora de IMC - JavaScript

Projeto desenvolvido para praticar lógica de programação, manipulação de DOM e eventos utilizando JavaScript puro.

## 📚 Conceitos praticados

* Manipulação de DOM
* Eventos com `addEventListener`
* Captura de dados de formulário
* Validação de entradas
* Condicionais (`if`, `else if`, `else`)
* Conversão de tipos (`parseFloat`)
* Manipulação de classes CSS
* Atualização dinâmica da interface
* Funções matemáticas com JavaScript

---

## ⚙️ Funcionalidades

A aplicação permite:

* Inserir peso e altura
* Calcular automaticamente o IMC
* Exibir o valor do IMC
* Mostrar a classificação do resultado
* Validar valores inválidos
* Exibir mensagens de alerta
* Mostrar resultado dinamicamente na tela

---

## 🧮 Fórmula utilizada

O cálculo do IMC é realizado utilizando a fórmula:

IMC = \frac{peso}{altura^2}
